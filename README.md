# Student Performance Data Analysis

This project analyzes student performance data using Python, Pandas, Matplotlib, and Jupyter Notebook.

## Project Overview

The dataset includes information such as:

- Gender
- Race/ethnicity
- Parental level of education
- Lunch type
- Test preparation course
- Math scores
- Reading scores
- Writing scores

## What I Did

- Loaded and analyzed CSV data using Pandas
- Checked the dataset for missing values
- Reviewed summary statistics
- Compared student performance across different categories
- Calculated average scores
- Created charts and visualizations using Matplotlib

- Jupyter Notebook
